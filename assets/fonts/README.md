# Bundled fonts

Goblin Flip bundles these Google Fonts families:

- Cinzel by Natanael Gama
- Cinzel Decorative by Natanael Gama
- Almendra by Ana Sanfelippo

Each family directory includes the original `OFL.txt` distributed with its
download from Google Fonts. The fonts are licensed under the SIL Open Font
License, Version 1.1.
